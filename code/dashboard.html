Every element is drawn from the PLC's own data block. Loads appear as the lane counters increment, the diverters fire on the sorting bits, and the vehicle shows the downstream handshake. When the vehicle is not ready, the interlock holds the load on the belt instead of releasing it.

Remote Control

Downstream Ready
The Downstream Ready switch writes Cmd_Downstream_Ready (DB1 30.5), which the interlock treats the same as the hard-wired handshake on I1.1. Turn it off, trigger a class sensor in PLCSIM, and the load is held.
